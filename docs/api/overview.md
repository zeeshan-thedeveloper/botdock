# API Overview

Status: In Progress

The NestJS API currently exposes:

- `GET /health`: service health status.
- `GET /docs`: Swagger/OpenAPI documentation.

Planned API groups:

- Authentication
- Organisations
- Bots
- Bot configuration
- Bot versions
- Knowledge sources
- Publishing
- Public chat runtime
- Conversations
- Analytics
- API keys
- Allowed domains
- Health checks
